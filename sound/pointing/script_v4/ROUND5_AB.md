# Round 5: two versions of the same true story, for a head-to-head read

Both versions use the same facts, the same places and about the same number of words (about 215, 63-66 s, one
narrator). They differ in what comes first.

N = narrator. H = a steam-train driver around 1910, C = his coal man, D = a train driver today.

---
